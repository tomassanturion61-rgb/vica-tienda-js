# vica-tienda-js

Script de conversión de la tienda VICA (Tiendanube): contador de la promo, beneficios y CTA para empresas en la ficha, bloques "Otras versiones" y "Completá tu equipo", y autoplay del carrusel.

Lo carga Google Tag Manager desde GitHub Pages. **No editar `vica.js` a mano**: se genera con `scripts/generar_gtm.py` desde el proyecto local y se publica con `scripts/publicar_js.ps1`.
